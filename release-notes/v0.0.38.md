SearchLauncher 0.0.38 fixes wallpaper theme updates and improves widget sizing.

- **Wallpaper colors keep following your swipes.** Returning to the image selected when the launcher opened now saves that selection correctly, so repeated cycles no longer leave the theme using the previous image's colors (#138).
- **Responsive widgets receive their displayed size.** The launcher reports widget dimensions to providers and updates them after resizing. Widgets also fill their allocated height. This addresses a hosting problem affecting multi-line and list widgets (#137).

Formatting, unit tests, and APK build checks passed. SmartSpacer and ToDo Agenda have not been verified on a physical device; please report any remaining failures with the widget configuration and device details.

Download **app-release.apk** to update the regular SearchLauncher installation.
