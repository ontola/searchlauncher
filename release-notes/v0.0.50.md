# SearchLauncher v0.0.50

## Your search waits for you

Typing a search, switching to another app to look something up and going back home used to clear what you had typed. Now the query is still there when you return, as long as it is less than five minutes old. Pressing home while you are already on the launcher still gives a clean home screen.

## Browser downloads that arrive intact

Saving an image from a site such as WeTransfer could leave a failed, empty `.bin` file in Downloads. Images are now saved from the page itself, so they arrive with their real name and extension. Other downloads send the page along as referrer and use the filename the server gives, including names in the `filename*` form.

## More search shortcuts for your apps

The built-in search shortcuts now come from a longer list. 29 apps, from Amazon and bol to GitHub, join your shortcuts once they are installed and stop being offered when you remove them. Shortcuts you remove stay removed until Reset Defaults.

## Validation

Formatting and store-copy checks, unit tests, and the release APK build ran in CI. This release includes pull requests [#163](https://github.com/ontola/searchlauncher/pull/163), [#166](https://github.com/ontola/searchlauncher/pull/166) and [#167](https://github.com/ontola/searchlauncher/pull/167).

The GitHub APK updates the regular installation of SearchLauncher. The Play production release is subject to Google's review.
