SearchLauncher 0.0.39 replaces broad storage access with Android's file picker.

- Downloads retains progress, history, opening, APK installation, and deletion for files downloaded through SearchLauncher.
- **Open a file** lets you choose a file from another app through Android's picker. SearchLauncher receives access to that selected file only.
- **Browse all downloads** opens Android's Downloads view for files saved by other apps.
- Removed All files access, legacy storage permissions, and automatic scanning of the shared Downloads folder. Other apps' files are no longer automatically listed inside SearchLauncher.

This version prepares the app for Google Play permission review; it does not mean Google has approved or published the app.
