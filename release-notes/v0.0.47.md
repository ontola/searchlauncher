# SearchLauncher v0.0.47

## See every search shortcut

While you type, the favorites row becomes a sideways strip of every search shortcut you can launch. Swipe to reach the rest. The last cell opens Custom Shortcuts, already expanded. Home favorites are unchanged.

## Ordered by use

Shortcuts start out most-used first, with the same unused Google and Play Store tilt as search results. In Custom Shortcuts, hold a handle and drag to set your own order. The strip follows that order. Reset Defaults returns to sorting by use, and a backup keeps a custom order.

## Validation

Formatting and store-copy checks, unit tests, and the release APK build ran in CI for each change. This release includes pull request [#159](https://github.com/ontola/searchlauncher/pull/159).

The GitHub APK updates the regular installation of SearchLauncher. The Play production release is subject to Google's review.
