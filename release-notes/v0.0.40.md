# SearchLauncher v0.0.40

This release improves browser downloads, fixes unreadable webpages and blank list widgets, and adds a default-browser prompt to onboarding.

## Browser improvements

- **Download JavaScript exports.** Files generated inside a page using `blob:` or `data:` URLs can now be saved instead of showing “Cannot download this file.” Transfers show progress and completed exports appear in Downloads, with the existing open, share and delete actions. Exports are limited to 100 MB; keep the source tab open until the transfer finishes.
- **Readable page backgrounds.** Pages without an explicit background use a white canvas. Dark tab or toolbar colors no longer turn transparent pages into black text on black. Website-defined backgrounds still apply.
- **Default-browser onboarding.** New users can choose “Set as default browser” or “Not now.” Android handles the choice, and users who already chose SearchLauncher are not prompted.
- **Native WebAuthn integration.** Browser tabs and link previews enable Android WebView's browser-mode authentication on supported Android 14+ devices. Older devices and unsupported WebViews remain usable without enabling the API.

## Widget fix

Merged #141 to correct initial sizing and refresh collection widgets, including multi-line list layouts that previously appeared blank. Android 12+ widgets now receive non-empty responsive size information. This follows up on #137.

## Availability and validation

Passkey support is **not yet verified end to end**. Google Password Manager requires privileged-browser approval for SearchLauncher's signing certificates; other providers may impose their own requirements. Adding the integration does not grant that approval.

Local formatting checks, store-text validation, unit tests and release build are checked before publishing. No physical Android device was connected for this release's browser fixes. The widget PR reports an emulator check with Android's Calendar collection widget; the exact Smartspacer device configuration still needs confirmation.

The website also now includes current screenshots, the app-use promo video, and fuller explanations of browser tabs, tab search and downloads.
