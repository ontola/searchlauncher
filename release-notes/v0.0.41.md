# SearchLauncher v0.0.41

## Open linked apps from browser tabs

HTTPS app links can now open the installed app selected by Android instead of always staying inside SearchLauncher. This addresses a missing handoff that can prevent services such as DigiD from opening their companion app.

- Android chooses the destination using its existing app-link settings.
- Ordinary webpages stay in SearchLauncher when there is no default app handler.
- The handoff does not open another browser or show an app chooser for ordinary navigation.
- Only main-page navigation can trigger this handoff, not embedded frames.

This change applies to browser tabs on Android 11 and newer. Link previews are unchanged.

## Validation

Five focused tests cover app handoff, unchanged URLs, browser/chooser exclusion, missing or denied handlers, and the Android 10 fallback. Debug build passed. The DigiD login flow has not yet been verified on a physical device; app-link settings on the device still apply.

Install the release APK to update the regular SearchLauncher app. A separately installed debug/preview app is not updated by this APK.
