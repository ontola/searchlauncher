SearchLauncher 0.0.37 makes search shortcuts clearer and tidies up animated results.

### Search shortcuts on the spacebar

- Type an alias such as **y** to see the full **YouTube** pill inside the built-in keyboard's spacebar.
- Press Space to activate it: the pill moves into the search bar with a quick animation. On split tablet keyboards, it starts from the half you press.
- An activated shortcut with an empty query, such as **y + Space**, shows **Search in YouTube** as the first action, beside the search bar. It remains available while background results load or refresh.
- Selecting that action opens the shortcut's search URL, even before you enter a search term.

### Cleaner result animations

- Reduced bottom padding to give the bottom result more even spacing.
- Clipped animated rows at the list boundary and kept the selected row above moving rows, so results do not show through underneath it.

### Installing

Download **app-release.apk** for the regular SearchLauncher app. This release includes the changes from the `results23` and `pill24`–`pill26` debug previews. It updates the regular app; debug previews are separate installations.
