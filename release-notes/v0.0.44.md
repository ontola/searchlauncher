# SearchLauncher v0.0.44

## See which websites use storage

Open **Settings → Browser → Website storage** to see a total and a searchable list of domains, with the largest storage users first. Clear a site's data or clear all website data to free space.

- Storage sizes are prominent on each domain's card.
- Clearing removes cookies, cached files and saved website data. A confirmation explains that you may be signed out or lose offline content.
- Clearing a domain also covers its related subdomains. Downloads and browsing history are kept.
- Sizes reflect storage reported by Android WebView, not the complete disk footprint: cookies, local storage and some cached files are excluded. Sites using only those may not appear, but **Clear all website data** still includes them.
- Older WebView versions show an update message if they cannot safely clear site data.

## Better swipe-down setup

Onboarding now asks whether your phone has separate notification and Quick Settings trays, so the tutorial and gestures fit phones with either layout. You can change this choice in Settings.

## Other changes

Includes the Android developer verification registration asset.

## Validation

The storage panel was tested with real website databases and cookies on an Android 15 emulator: cancellation preserved data, and clearing one site left an unrelated site's data intact. The USB-installed debug build was also checked and approved on a Xiaomi phone.

The release APK updates the regular GitHub installation; it is separate from SearchLauncher Debug.
