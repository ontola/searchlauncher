# SearchLauncher v0.0.45

## Open web addresses reliably

Typing an address now offers **Open website** even for hosts that the old URL matcher missed, such as `ontola.staging.atomicserver.eu`, `localhost`, an IP address, or an address with a port and path. A typed address also ranks above learned apps and open tabs, so pressing Go takes you to the site. Ordinary words still search normally.

## Clear means clear

Clearing a search, returning Home, or opening a result now removes the visible text from the search box as well as resetting the results. The old text could remain on screen because the keyboard still held an unfinished edit.

## Recognize pages at a glance

Bookmarks, browsing history, and open tabs now show their web address below the page title. The selected result keeps readable contrast on page-colored result panels.

## Send feedback with useful context

Settings now has **Send feedback**. You can write a report and optionally include an email address. The report includes device, Android, WebView, and SearchLauncher version details to help diagnose problems. Sending feedback does not change your crash-reporting preference.

## Validation

Formatting and store-copy checks, debug and release unit suites, and the release APK build passed. This release includes the fixes merged in pull requests [#150](https://github.com/ontola/searchlauncher/pull/150), [#151](https://github.com/ontola/searchlauncher/pull/151), [#152](https://github.com/ontola/searchlauncher/pull/152), and [#153](https://github.com/ontola/searchlauncher/pull/153).

The GitHub APK updates the regular installation of SearchLauncher. The Play production release is subject to Google's review.
