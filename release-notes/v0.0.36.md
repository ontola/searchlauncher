SearchLauncher 0.0.36 makes the built-in keyboard more useful, adds a full Downloads page, and brings subtle motion and more consistent layouts to home search.

### Keyboard gestures

- **While searching:** swipe sideways on the keyboard to move the text cursor, or up/down to scroll results. Flick to keep scrolling with momentum. Releasing a swipe no longer opens a result; tap a result or press Go to open it.
- **With an empty query:** swipe up for the app drawer, down on the left for notifications, down on the right for quick settings, and sideways to change wallpapers.
- Touch scrolling and keyboard scrolling now share native list momentum handling, so an earlier fling does not fight your next gesture.
- A dedicated **Settings → Keyboard** panel contains the built-in keyboard and gesture options. Gestures are enabled by default. Normal taps and long-press accents remain available.

### Search that feels more responsive

- New results fade in with a brief stagger; existing results move to their updated positions instead of restarting their entrance on every letter.
- Favorites and search shortcuts transition when you start or clear a query. Keyboard colors blend when the wallpaper theme changes.
- Removed the duplicate search-engine icon beside the Clear button.
- Cached search becomes available before database setup finishes. Less work runs on each keystroke, icon lookups move off the UI thread, and background index loading yields to typing.
- Fixed startup movement caused by late navigation-bar spacing and reduced repeated layout updates during favorites animations.

### Downloads in one place

- Search for **Downloads** (or **files**) to open download history and live progress.
- Download links open the downloads experience instead of leaving a blank browser page.
- Download cards show status, file size, and date, with **Install APK / Open file**, **Open with**, **Show in Files**, and **Delete / Cancel** actions.
- APK installation guides you through Android’s install permission and resumes afterward.
- Choose **Show all downloads** to include files saved by other apps in the shared Downloads folder. Android asks for file access; the page scans only that folder and its subfolders. Other apps’ private download histories and live progress are not exposed.
- The Downloads page covers the status and navigation areas and uses a consistent full-screen transition.

### Wallpapers, tabs, and widgets

- Wallpapers use a cover crop on tablets and extend behind favorites and the search bar, while keeping the OS navigation area separate.
- Home keeps its keyboard and search-bar positions during sideways tab transitions. The return swipe uses a complete captured home view when available, rather than a wallpaper-only placeholder.
- Selecting a tab preview hides search controls during the card expansion.
- Replacing an unavailable widget opens the regular focused widget search instead of a separate keyboard-less picker.

### Installing this release

Use **app-release.apk** below for the regular SearchLauncher app. The earlier APKs with labels such as `downloads22` were separate debug previews; this release updates the regular app, not the debug installation. Backups can transfer settings between them.

This release includes all changes from those previews. Tablet smoothness remains an area for further tuning; the startup and animation changes reduce unnecessary work but do not guarantee a particular frame rate on every device.
