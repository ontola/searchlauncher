# SearchLauncher v0.0.48

## Calculator keys

The calculator now accepts the extra math keys on the home keyboard. × and ÷ work like multiply and divide. √ is a square root, including √(4+5) and 2√9. π is the circle constant, and writing it next to a number multiplies, as in 2π. A degree mark does not change the number, so 180°-45° is 135. A negative square root shows no calculator result. Phone-shaped queries such as 06-12345678 still do not open the calculator.

## Search shortcuts

While you type, every launchable search shortcut scrolls sideways, and the last cell opens Custom Shortcuts. The list is ordered by how often you use each shortcut. Hold a handle in Custom Shortcuts and drag to set your own order. Reset Defaults returns to sorting by use.

## Validation

Formatting and store-copy checks, unit tests, and the release APK build ran in CI. This release includes the search-shortcut work from 0.0.47 and the keyboard math operators.

The GitHub APK updates the regular installation of SearchLauncher. The Play production release is subject to Google's review.
