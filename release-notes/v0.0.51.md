# SearchLauncher v0.0.51

## WeTransfer downloads that work

Tapping Download on WeTransfer in the browser used to leave an empty entry in Downloads, marked "Download failed: the server refused it (HTTP 404)". WeTransfer's download links work only once, and the browser spent that one request before handing the link to Android's download manager.

Now SearchLauncher recognises WeTransfer download links and fetches the file itself, once, with the page's cookies. It arrives with its real name, shows its progress in Downloads, and keeps going if you leave the browser during a large transfer.

## Validation

Formatting and store-copy checks, unit tests, and the release APK build ran in CI. This release includes pull request [#169](https://github.com/ontola/searchlauncher/pull/169).

The GitHub APK updates the regular installation of SearchLauncher. The Play production release is subject to Google's review.
