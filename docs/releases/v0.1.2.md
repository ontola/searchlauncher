# SearchLauncher 0.1.2 — accurate backup sizes and clearer downloads

## What changed

- **Correct backup sizes.** The export confirmation now counts the bytes written instead of relying on file-provider metadata, which could report 0 B for a valid backup. Success is shown only after the output is closed. The backup format is unchanged.
- **Download speed and remaining size.** Active downloads show transfer speed and the megabytes still to download when the total size is known.
- **Choose your browser.** The built-in browser can be disabled in settings. Fixed the misleading “no browser app installed” error when other browsers are available and SearchLauncher is the default.
- **Finish editing widgets naturally.** Pressing Home or leaving the launcher exits widget edit mode.
- **Cleaner diagnostics.** Crash reporting now uses Sentry; expected errors and cancelled operations are handled more accurately.

## Updating

The GitHub `app-play.apk` uses the same signing identity as Google Play, allowing updates between those two channels when the version code permits. The legacy `app-release.apk` retains its separate signature for existing GitHub/F-Droid installations. Development builds use separate Debug identities to avoid interfering with Play installs.

## Validation

The backup regression tests verify exact UTF-8 byte counts, export/import round trips and failure reporting when the output cannot close. The optimized Debug Gecko build containing the backup fix was installed on a physical Xiaomi phone. This release does not claim to resolve the separately investigated tab-return freezes.
