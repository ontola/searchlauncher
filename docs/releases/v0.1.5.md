# SearchLauncher 0.1.5: custom swipes, number row, accent-free search

## What changed

- **Choose what each swipe does.** A new Gestures card in Settings has a row per home-screen swipe (up, down on the left, down on the right, left, right). Each can open notifications, Quick Settings, the app drawer, the next or previous background, an app of your choice, or do nothing. Keyboard swipes and pulling down on widgets follow the same choices. The old "Separate Quick Settings swipe" toggle is replaced by the down-right choice, and its saved value still sets that swipe's default. Closes #161. Includes [PR #199](https://github.com/ontola/searchlauncher/pull/199).
- **Number row on the built-in keyboard.** Settings > Keyboard can add a row of digits above the letters. Letter keys keep their size; the keyboard grows a little. With the row on, the top letter row long-presses to symbols instead of digits. Closes #165. Includes [PR #197](https://github.com/ontola/searchlauncher/pull/197).
- **Search ignores accents.** "tel" finds "Téléphone" and "tél" finds "Telegram". A result whose accents match the query ranks just ahead of one that differs. This also applies to open tabs, history, widget search and contact subtitles. Closes #190. Includes [PR #200](https://github.com/ontola/searchlauncher/pull/200).
- **Always request desktop sites.** A browser setting, off by default, starts new tabs in desktop mode. Each tab can still switch from its menu. Closes #193. Includes [PR #196](https://github.com/ontola/searchlauncher/pull/196).
- **Rounded icons in favorites.** Bookmark, tab and contact icons in the favorites row get rounded corners, like app icons. Includes [PR #179](https://github.com/ontola/searchlauncher/pull/179).
- **WebView build for F-Droid.** The legacy `app-release.apk` is now built with Android WebView instead of GeckoView, so F-Droid can rebuild it from source (#175). The `app-play.apk` and the Play Store version keep GeckoView. Includes [PR #198](https://github.com/ontola/searchlauncher/pull/198).

## Updating

The GitHub `app-play.apk` uses the same signing identity as Google Play. The legacy `app-release.apk` keeps its separate signature for existing GitHub/F-Droid installations, and from this version uses the WebView browser engine.

## Validation

Each change passed CI (build and unit tests) before merging. The swipe actions, number row and accent folding have unit tests. None of the changes were checked on a device for this release.
