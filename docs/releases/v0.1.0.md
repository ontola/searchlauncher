# SearchLauncher 0.1.0 — a new browser, built into your launcher

SearchLauncher now uses Gecko, the Firefox browser engine. This brings the browser integration
we have been testing in the separate Gecko app into the regular SearchLauncher release.

## What changed

- **Smoother browsing:** SurfaceView rendering, less work during scrolling, longer-lived recent
  tabs, and recovery when Android stops a page.
- **Websites as apps:** install supported websites from the browser menu and launch them from
  favorites in standalone or fullscreen mode. Browser controls return when a link leaves the
  app's scope. Long-press the favorite to open it in the browser or remove app mode.
- **Faster search:** quicker first results and typing, first-letter favorite matching, and more
  built-in search shortcuts for searching inside apps and websites.
- **Better downloads:** downloads stay in SearchLauncher, keep their place when finishing, show
  progress notifications and accurate sizes, and can be cancelled.
- **More consistent visuals:** dark/OLED appearance, subtle site-colored search surfaces, readable
  controls, and navigation colors that follow home/tab swipes.
- **Browser improvements:** fullscreen pages and video, protected-media initialization, file
  uploads, app-link handoffs, and local website notifications that return to the right app.
- **Favorites and backups:** refresh changed site icons and include cached bookmark icons in new
  exports. Older exports never contained these icons; visiting a site can restore them.

## Updating

Update the regular SearchLauncher app normally. Your launcher settings, favorites and bookmarks
stay in place. Website cookies, open-page sessions and site storage are not migrated from WebView
to Gecko, so save any important open pages and expect to sign in to websites again.

The separate SearchLauncher Gecko testing app remains a separate installation. Export/import can
transfer its launcher data; it does not transfer website sign-ins or installed-app mode metadata.

## Current limits

Website notifications work while Gecko is running. **Remote Web Push after the browser process
closes is not yet configured.** Passkeys depend on your credential provider's browser policy;
Proton Pass compatibility is not claimed. Per-site storage totals and private popup windows are
not yet supported. The bundled engine makes the APK larger; Google Play delivers the architecture
needed by your device.
